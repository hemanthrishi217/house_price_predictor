AI-Powered House Price Predictor
📌 Project Overview
This project is a Supervised Machine Learning application that predicts housing prices based on demographic and property features. Using the USA Housing Dataset from Kaggle, the model identifies patterns between income, house age, and the number of rooms to provide an estimated market valuation.

🚀 Features
Predictive Modeling: Uses a Multiple Linear Regression model trained on 5,000 records.
Interactive Dashboard: A clean, user-friendly UI built with Streamlit.
Real-time Estimation: Get instant price predictions by adjusting sliders for house age and room count.
Data-Driven Insights: Leverages real-world data processing techniques including data splitting and feature scaling.

🛠️ Tech Stack
Language: Python
Libraries: Pandas, NumPy, Scikit-Learn
Deployment/UI: Streamlit
Dataset Source: Kaggle (USA Housing Dataset)
